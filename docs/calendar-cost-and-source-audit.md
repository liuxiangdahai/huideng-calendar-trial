## 费用与运行位置

2026-11-04通过GitHub读取确认`liuxiangdahai/huideng-calendar-trial`为PUBLIC。当前工作流使用`ubuntu-latest`标准托管运行器，未使用大规格运行器。公开网站与公开仓库是两回事；本次仓库本身也确已公开。

| 部分 | 在哪里运行 | 当前官方免费范围及边界 |
|---|---|---|
| 定期资料检查、构建、测试、发布 | GitHub Actions | 公开仓库的标准托管运行器免费；大规格运行器不是。仓库公开不把Cloudflare也变成无限免费 |
| 网页、图片、JS/CSS | Cloudflare Pages | 不调用Functions的静态资源请求免费且不限次数 |
| 保存设置、生成和获取订阅 | Pages Functions / Workers | Free方案合计每日100,000请求；还有CPU等限制，不能只看访问人数 |
| 匿名设置、日程及快照 | Cloudflare D1 | Free方案每日500万行读取、10万行写入、账号总计5GB存储；这是数据库行数，不是用户数 |

GitHub自动任务只在运行时分配机器，结束后释放；日历后台由Cloudflare托管，不需要另租常驻服务器，也不要求用户电脑开着。每天检查一次、无变化不发布；来源失败继续服务旧有效资料。频率和短期存档策略应避免不必要的资源消耗。
