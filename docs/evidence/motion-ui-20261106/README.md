# 轻量动效与互动层次 · 2026-11-06

本轮按用户要求增加操作反馈，沿用现有纸色、绛红、古金、深青。每日藏历仍与方案区共享纸底，不增加新的彩色块。截图仅代表本地正式构建的浏览器模拟；不证明真实手机通知或直连网络。

## 交互规范

| 操作 | 反馈 | 不受影响的行为 |
|---|---|---|
| 鼠标悬停、按压 | 按钮轻抬1px、图标轻抬2px，按下回落 | 触屏无悬停；点击区不缩小 |
| 方案/单项/每日日期选择 | 勾选符号180ms确认 | 立即更新设置；重复相同方案不重建DOM或重播 |
| 上下月及跨月选择 | 月格横移8px、200ms淡入 | 保留六行、当天标记、焦点，最新操作立即生效 |
| 日期详情、两种预览、手机标签 | 180ms淡入 | 阅读锚点不移动，恢复各自滚动位置 |
| 展开分类/帮助 | 用户打开时内容180ms淡入 | 原生details立即打开；重新渲染不重播 |
| 设置/时区/订阅弹窗 | 180ms淡入与8px出现 | 原有居中、关闭、键盘焦点、滚动不变 |

动效仅用opacity/transform或独立translate；没有循环动画、粒子、滚动视差、42格逐项动画、首屏延迟显现或新图片/字体。只使用用户动作之后的反馈；没有将动画完成作为保存或跳转的前提。

## 可访问性与降级

系统“减少动态效果”同时关闭CSS动画和伪元素过渡，取消正在播放的Web Animations；运行时修改系统偏好立即生效。动画API缺失时跳过效果，正常进行设置、翻月和弹窗。页面隐藏时取消脚本动效，连续操作覆盖旧效果，完成后清理引用。

## 证据与当前结果

- `layout-review.json`：320、390、545、585、768、1024、1440px两种面板无横向溢出；月历42格；订阅弹窗无溢出、错误后复制入口仍可用，0页面脚本错误。
- 手机/电脑同状态截图及正常/错误订阅面板保存在本目录。固定底栏的全页截图可能出现在截图中段，实际页面随视口固定，不能据此推断长页内容被永久遮住。
- 日期、服务、构建143项通过。三浏览器最终运行及性能复测结果将在发布前补充。
- 首轮测量保留：7类交互各30次，方案Event Timing p95为208ms，超过200ms目标；100次连续操作无设置丢失。已移除多余的底部摘要淡入，摘要改为直接更新，复测待补充。
- 代码复核修正：日期详情是手机阅读锚点，因此只用opacity；同一方案再次点击直接返回，避免反复渲染。
- Firefox复测发现缓存的MediaQueryList偶尔仍保留旧偏好，而新的查询已变更；已定位为动效被提前跳过。处理方式是动作发生时读取最新偏好，保留原查询监听以取消正在播放的效果；回归同时核对动画实际对象与最终状态，不用等待自然结束代替取消验证。
- 跨浏览器测试使用键盘进入弹窗后验证Escape焦点恢复，不假定Safari鼠标点击必定聚焦按钮；阅读位置测试先选日期再滚到详情，避免程序点击屏外日期触发Safari自身滚动，仍严格检查中途切换标签时的位置与选中日期。
