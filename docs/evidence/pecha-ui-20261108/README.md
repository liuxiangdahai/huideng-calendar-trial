# 2026-11-08 · 经页·香布界面改版证据

分支 `claude/uiux-pecha-redesign`，基线 `0c0b16c`。截图均来自本地正式构建（`npm run build:local` → `dist/site`），本机 Chrome，内存数据库；不是线上或真机截图。

## 设计决定

| 元素 | 取自 | 用法 |
|---|---|---|
| 边玛墙 | 寺院墙顶的绛红草墙 | 页头绛红底加细竖纹、双道金线；品牌改为横排“藏历 · 慧灯小组” |
| 香布 | 门窗上方的褶裥彩幔 | 雪山横幅下缘与弹窗顶部的四色褶带（CSS 绘制，无图片），全站唯一多色元素 |
| 经页 / 唐卡边 | 经页留白与唐卡内框 | 主内容一层内框细线；标题以金色短线收于一颗“诺布”菱形 |
| 八吉祥 | 莲花、法轮、宝伞、胜利幢、宝瓶、吉祥结及铃杵、日月 | 七个分类与三套方案统一重绘，同一 24 单位网格和线宽 |
| 印章 | 朱印与金边 | 选中方案的勾、今天的日期都是绛红圆印外加一圈金线；选中日期改为金色细框，两者不再叠加 |

色彩角色收为：绛红=操作/选中/提醒，深青=结构与标题，古金=细线与装饰（不用于正文），暖纸=底。日程标签只用两种：开启提醒为绛红，仅显示为暖灰。

新增：横幅显示“下一个荟供日”（莲师/空行母，按同一藏历 PRO 规则计算，只读，不改选择；空闲时计算，手机预留行高避免位移）。

撤下：四个孤立 SVG（角花、卷草、结饰分隔、云纹），横幅右侧菱形标记。

## 性能（本机合成，见 `performance-summary.json`）

- 冷启动 LCP p95：改版前 928/968ms，改版后 940ms；CLS 修正后为 0（初版手机横幅第三行出现时有 0.009 位移，已用预留行高修正）。
- 冷启动最长主线程任务：两次基线 203–263ms，改版后 219–283ms，处于同一波动范围。原有冷启动长任务问题**仍未解决**，本轮没有改善。
- 交互 p95：方案 80–112ms、勾选 80–88ms、翻月 72–80ms；100 次连续操作设置全部保留。
