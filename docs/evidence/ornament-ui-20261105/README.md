# 纹样与界面整理验收 · 2026-11-05

本目录为正式构建源码的本地候选证据，随实现提交保存；最终线上版本由既定流水线重建并复核。所有截图均为浏览器模拟，不替代真机触控、直连网络或日历通知证据。

## 本轮变化

- 每日藏历成为方案区域底部的独立复选项，默认关闭，展开示例不改变选择；根据用户追加反馈撤下青灰背景，与三方案统一暖纸底、墨色标题和古金图标。
- 原创卷草角花与结饰分别用于月历边缘、选择区标题及详情分隔，两张 SVG 共 1096 bytes。参考原图仅在本机资料包，不进入公开仓库和网页。
- 收拢厚重标题底色和重复分隔；当前月份深色文字、邻月较淡文字，保持可读对比度。日程全名使用系统正文，详情支持长名称和同日五项。
- 正常连接状态一行展示，检查时间与诊断折叠；失败自动展开。Google/Outlook的复制→打开步骤、Apple直接添加和失败备用入口保留。

## 已完成检查

| 检查 | 证据与结论 |
|---|---|
| 日期/服务/构建 | `npm run check:calendar`：143项通过；日期数据与公开feeds无差异 |
| Chromium / Firefox / WebKit | `npm run test:browser:all`：各60项，共180项通过 |
| 本轮行为风险 | 示例展开与键盘勾选彼此独立；每日单独订阅、旧选择、方案切换、清空、保存失败、固定地址继续通过；连接详情被收起后发生失败会自动展开 |
| 尺寸 | 320/390/545/585/768/1024/1440px无横向溢出；390×844每日选项在首屏底栏上方；更小/更短窗口可滚动到所有操作 |
| 月历 | 完整42格、原名详情、重日/闰月、长名称/同日五项、今天与选中状态分别通过 |
| 布局与操作 | 既有横屏、短屏、200%等效重排、键盘及吸顶切换回归通过；模拟尺寸不等同真实系统软键盘验收 |
| 对比度 | 当前/邻月日期及藏历字、选中方案文字均通过4.5:1检查；修正了邻月原候选4.497:1的不足，没有降低标准 |
| 运行错误 | `layout-review.json`中页面脚本错误0；失败状态中复制按钮仍可用 |

初轮两类旧断言把“渐变填充”和“邻月底色必须更亮”当成功能要求；已改为验证真实选中差异、日期层次和4.5:1可读性。保留并执行原来的交互与稳定地址检查。
