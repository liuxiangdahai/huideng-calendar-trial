# 慧灯藏历 · 中文使用说明

更新日期：2026-10-29。本说明对应 Pages 统一入口版本；技术测试通过与真实手机验收分别记录在验收报告中。

试用入口：[慧灯藏历](https://huideng-calendar-trial.pages.dev/calendar-reminders/)。本阶段新建订阅的公开地址统一使用该 Pages 网站，订阅路径为 `/calendar/… .ics`（实际地址没有空格）。请使用网页生成的完整地址，不要自行替换地址内容。我们不会索取你的日历账号密码，也不会读取个人日历。

## 先选内容，再添加到日历

1. 在“选择内容”中点选快捷方案，或展开分类逐项选择。首次访问不默认勾选。
2. 需要通知的项目点“调整提醒”，设置当天或提前提醒及具体时间；最多两次。仅想在日历中看到日期的项目使用“仅显示”。
3. 切换“日期预览”查看月历或列表。日程名称保留佛慧法语原名，缺日、重日和闰月按实际资料处理。
4. 点“订阅到日历”，选择实际使用的应用，按对应步骤添加。

三个方案分别是“莲师荟供”“两个荟供日”“全部修行日”。全部修行日当前包含 54 项，只有两个荟供日开启提醒，其余仅显示；不包含节气和其他纪念日。方案选好后仍可逐项调整。

日程全天显示，通知按你选择的提醒时区计算。页面的“今天”和设备时间跟随当前设备；更改提醒地区不会自动改写各项目的提醒时间。旅行后，手机可能把同一提醒时刻显示为当地的另一个时间，甚至前一天。请在日程详情中核对两地时间，按需要保存修改。

## Apple 日历：iPhone、iPad、Mac

### iPhone / iPad

在 Safari 中打开本页，准备好地址后点“打开 Apple 日历订阅”，在系统日历窗口确认添加。按钮是否能唤起应用，仍取决于浏览器及系统；网页不会把点击按钮记作订阅成功。

如未打开，复制本页的 HTTPS 订阅地址，在 Apple“日历”应用中依次打开底部“日历”→“添加日历”→“添加订阅日历”，粘贴后点“查找”，并按提示确认。旧版界面可能显示“订阅”。

需要提醒时，找到“慧灯藏历”旁的信息按钮，检查“日程提醒”；再到系统“设置”→“通知”→“日历”检查“允许通知”。菜单因系统版本不同可能有所变化，可直接使用网页内的中文步骤卡。

[Apple 中文订阅说明](https://support.apple.com/zh-cn/guide/iphone/iph3d1110d4/ios)

### Mac

可以点“打开 Apple 日历订阅”，也可以在 Mac“日历”中选择“文件”→“新建日历订阅”，粘贴 HTTPS 地址并确认。需要在其他 Apple 设备查看时，在“位置”选择 iCloud，并使用同一 Apple 账户。

检查订阅设置中的“忽略提醒”和“移除：提醒”，以及 Mac 系统通知权限。其他设备的通知权限仍需分别检查。

[Mac 中文订阅说明](https://support.apple.com/zh-cn/guide/calendar/icl32362/mac)

### 微信或钉钉中打不开 Apple 日历

网页会提示先转到 Safari 或系统浏览器。点右上角“…”菜单，查找“在浏览器中打开”或“在 Safari 中打开”；没有这个入口时，使用“复制网页地址”，到 Safari 粘贴打开。

- 尚未生成订阅：到外部浏览器重新选择内容，再准备订阅；微信中的本机草稿不会自动带过去。
- 已生成订阅：可在“管理这份订阅”中复制管理链接，在自己的 Safari 中打开，继续修改同一份订阅。管理链接只自己保存，不要转发。
- 已有 HTTPS 订阅地址：也可按上方手动步骤在 Apple 日历添加。

Apple 入口在这些内置浏览器中不会自动新建订阅，也不会反复尝试无法打开的日历按钮。

## Google 日历

在电脑浏览器登录手机正在使用的 Google 账号。复制订阅地址，点“打开 Google 日历添加页面”，粘贴地址后确认添加。若没有直接进入添加页，在左侧“其他日历”旁点加号，选择“通过网址添加”。

随后在手机 Google 日历中确认已显示“慧灯藏历”及其日程。网页设置的逐项提醒可能不会保留；请检查该日历实际提供的通知选项和系统通知权限。若没有相应选项，本网页无法强制开启。同步由 Google 日历决定，不保证即时出现。

[Google 中文添加说明](https://support.google.com/calendar/answer/37100?co=GENIE.Platform%3DDesktop&hl=zh-Hans) · [Google 中文通知说明](https://support.google.com/calendar/answer/37242?co=GENIE.Platform%3DAndroid&hl=zh-Hans)

## Outlook：网页版、经典 Windows 桌面版

### 网页版

复制订阅地址，打开 Outlook 网页日历。在侧栏选择“添加日历”→“从 Web 订阅”，粘贴地址并按页面要求填写名称，再点“导入”或相应确认按钮。工作或学校账号请使用所在组织的 Outlook 网页。

### 经典 Windows 桌面版

打开 Outlook 日历视图，在“开始”选项卡的“添加日历”菜单选择“从 Internet”。粘贴地址，点“确定”，在询问是否订阅更新时选择“是”。新版 Outlook 或没有该入口的版本可使用网页版步骤。

不能订阅时，可下载本页的 .ics 文件，在网页版“添加日历”→“从文件上传”中导入。文件导入不会持续更新。

Outlook 自行决定同步时间，更新可能超过 24 小时。订阅日历的提醒能力也因版本和账号不同而变化；请检查日程实际显示的提醒及系统权限，不以网页设置作为通知已经生效的依据。

[Outlook 中文网址订阅说明](https://support.microsoft.com/zh-cn/outlook/import-or-subscribe-to-a-calendar-in-outlook-com-or-outlook-on-the-web) · [经典桌面版中文说明](https://support.microsoft.com/zh-cn/outlook/training/import-calendars-into-outlook)

## 其他日历

先在应用中确认是否支持“网址订阅”或 .ics 文件导入，再按网页步骤选择一种方式。华为、OPPO／一加、小米／REDMI 的已核实帮助与适用版本在“其他日历”中直接展开查看。品牌相同不代表所有系统版本都支持同一种功能。

网址订阅可在应用同步后收到后续更新；文件导入只把当时的日程复制进日历。重复导入前先删除旧的专用日历，避免重复。仅显示模式还应检查并关闭日历应用自带的默认通知。

## 看懂连接状态

| 网页显示 | 实际含义 |
| --- | --- |
| 尚未准备 | 尚无订阅地址，先选择日历应用并完成准备。 |
| 正在准备／保存 | 请求处理中，请稍候；重复点击不会重复创建。 |
| 地址已生成 | 地址已经可用，可添加、复制或使用文件导入。 |
| 本次连接检查正常 | 本网页这一次读取到了有效日历文件；不代表手机已订阅或已同步。 |
| 本次连接检查失败 | 本次请求超时、网络失败或返回内容异常；地址仍保留，可重试检查。 |
| 设置已保存，等待日历同步 | 服务器已经保存，手机何时更新由日历应用决定。 |
| 已停用 | 服务端订阅已停用；仍需到自己的日历应用移除这份订阅。 |

新建地址后自动检查一次；此后由你点“检查连接”或“重试检查”，不会持续后台轮询。检查时间使用当前设备时间。检查失败不会隐藏复制地址和文件导入。

“我已看到日程”“我已检查提醒”由你在实际核对后自行勾选，只保存在这个浏览器。换到另一份订阅需重新确认。复制地址、下载文件、返回网页或连接正常，都不代表日历已经订阅成功。

## 失败时怎么继续

- **网页准备或保存失败：**本机草稿保留，先检查网络，再点重试。创建响应丢失时会尝试恢复同一份订阅，无需反复建立新订阅。
- **Apple“查找／Find”一直等待：**取消当前查找，先在网页点“检查连接”，再尝试切换 Wi-Fi 或移动网络，并使用完整 HTTPS 地址手动添加。网页正常不代表日历应用的取数也正常。
- **出现不安全连接或证书警告：**停止添加，不关闭 SSL，不忽略警告。记录提示原文、系统版本、网络类型和地址协议前缀供核查；不要公开完整个人订阅地址或管理链接。更换为 Pages 地址不等于该问题已在所有设备解决。
- **连接仍不可用：**可临时使用文件导入，但它不会持续更新；在真实网络验收通过前，不将这个方式计为长期订阅成功。

## 返回修改与免登录管理

同一网站、同一浏览器会记住选择和管理凭证。修改后点“保存修改”，个人订阅地址保持不变。可以在“我的订阅”→“管理这份订阅”中复制管理链接，供换设备恢复；后台匿名保存设置，无需注册会员。

管理链接能修改和停用订阅，只自己保存。订阅地址只用于读取日历，也不宜公开分享。如果管理链接丢失且浏览器数据被清除，将无法找回原订阅；需要在日历应用移除旧项后重新建立。

可选的“十分钟提醒测试”仅验证一次文件导入的提醒能力。它不能代替长期订阅的同步、更新、撤销和真实通知验收。真机尚未验证的组合继续标记为待验收。
